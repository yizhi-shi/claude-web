# 中英文界面（i18n）

> 状态: current
> 最后核对: 2026-11-24
> 事实源: `web/src/i18n.ts`、`web/src/views/`、`web/src/components/`
> 关联: [UI 设计](UI-DESIGN.md) · [功能对照](FEATURE-PARITY.md) · [Roadmap](ROADMAP.md)

## 目标与范围

控制台界面支持 **简体中文 / English** 切换，不改变服务端数据、会话内容或 Claude 的输出语言。

覆盖范围：

- 登录/首次初始化、侧栏、会话空间、新建会话面板；
- 聊天头部、运行状态条、输入区、附件、命令/技能/文件菜单；
- 权限审批、AskUserQuestion、ExitPlanMode 面板；
- 消息、思考、工具卡片、diff/输出；
- 设置页、语音识别设置、会话设置（模型/权限/扩展/状态）；
- 语音按钮状态、常见 toast 和常见服务端错误。

不覆盖：

- Claude/CLI 返回的正文、命令说明、工具名和用户数据；
- 未知的服务端错误字符串（没有对应字典项时保留原文）；
- 第三方 provider 返回的文本。

## 选择与生效

```text
首次访问：localStorage cw.locale → 浏览器 navigator.language → zh / en
切换：登录页语言按钮 / 侧栏底部「English / 中文」/ 设置 → 外观 → 界面语言
持久化：localStorage，按浏览器保存
HTML：document.documentElement.lang = 'zh-CN' | 'en'
```

语言是**前端视图偏好**，不需要服务端重启，也不写入 `data/preferences.json`。因此不同浏览器可以各自使用中文或英文。

## 实现

`web/src/i18n.ts`：

- `locale`：Vue `ref<'zh'|'en'>`；
- `t(source, params?)`：中文源串作为 key，英文查表；支持 `{name}` 插值；
- `setLocale` / `toggleLocale` / `initLocale`；
- `translateServerMessage`：常见服务端错误的中文→英文映射（含账号锁定/频率限制等模式）；
- `EN` 字典：集中维护英文文案。

组件通过 `import { t } from '../i18n'` 在模板和脚本中调用 `t('中文源串')`。`t` 读取 `locale.value`，所以 Vue 渲染会随语言切换自动更新。

## 文案维护规则

1. 新增 UI 文案时，中文写进模板/脚本，同时给 `EN` 增加对应项；不要只改中文。
2. 带变量用 `{name}`、`{n}` 等占位符，避免手工拼接语序。
3. 日期/相对时间/时长统一走 `utils.ts` 的 `formatRelative` / `formatDuration` / `statusLabel`，这些函数已经调用 `t`。
4. 服务端新增错误码时，优先在 `translateServerMessage` 增加精确匹配；动态数字用正则模式。
5. 不要翻译用户输入、Claude 正文、工具原始输出、模型名、路径和代码。

## 文档双语策略

界面双语之外，公开文档按“入口双语 + 中英文档索引”维护，避免所有长文档双份漂移：

| 层级 | 文档 | 维护方式 |
|---|---|---|
| 入口（完整双语） | `README.md` / `README.en.md`；`SECURITY.md` / `SECURITY.zh-CN.md`；`CONTRIBUTING.md` / `CONTRIBUTING.zh-CN.md` | 改一份必须同步另一份；每份顶部有语言切换 |
| 设计事实源（中文） | `docs/ARCHITECTURE.md`、`IMPLEMENTATION.md`、`ATTACHMENTS.md`、`EXTENSIONS.md`、`DEPLOYMENT.md`、`VOICE-ASR.md`、`UI-DESIGN.md`、`FEATURE-PARITY.md`、`ROADMAP.md`、`COMPETITIVE-RESEARCH.md`、`I18N.md` | 中文是唯一事实源；中英文索引分别维护条目和摘要 |
| 文档索引（双语） | `docs/README.md` / `docs/README.en.md` | 两边列出全部文档和一句话说明；设计文档变化时同步更新两个索引 |

同步检查清单：

1. UI 文案：中文源串与 `web/src/i18n.ts` 的 `EN` 字典同时更新，跑一次缺失 key 检查。
2. 入口文档：`README.md`/`README.en.md`、`SECURITY.md`/`SECURITY.zh-CN.md`、`CONTRIBUTING.md`/`CONTRIBUTING.zh-CN.md` 成对修改。
3. 设计文档：修改中文正文后，更新 `docs/README.md` 和 `docs/README.en.md` 对应条目；若新增设计文档，必须同时加入两个索引。
4. 提交前跑 `npm run build`；文档改动不需要重启服务。

## 已知限制

- 服务端仍返回中文错误；只有常见错误被前端翻译，未知错误保留原文。
- CLI `system/init` 提供的命令/技能描述由 CLI 生成，语言取决于本机配置。
- 语言偏好不跨浏览器同步；没有服务端“默认语言”设置。
- 英文文案按控制台语境翻译，不追求逐字对应中文。
