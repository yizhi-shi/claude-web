# Roadmap

> 状态: current
> 最后核对: 2026-11-24
> 关联: [功能对照](FEATURE-PARITY.md) · [架构](ARCHITECTURE.md) · [语音](VOICE-ASR.md)

## 已具备（v0.6）

- 首次初始化 + 账号密码登录 + 同账号 5 次失败锁定 1 小时
- 服务端常驻会话；刷新/关页面不中断，重开自动附着并回放
- 流式文本/思考、工具卡片、命令输出、文件 diff
- 权限审批（一次/会话/拒绝）、超时拒绝、默认全部允许
- 交互式提问（AskUserQuestion）与计划确认（ExitPlanMode）：原生面板、单选/多选/自由输入、跳过、批准/退回、刷新恢复
- 会话历史扫描、续聊、最近窗口加载
- 实时执行状态：当前工具、耗时、后台任务、上下文用量、费用、压缩提示
- 工作区目录配置（默认/额外/新建文件夹）
- `/` 命令与 Skill 菜单、`@` 文件引用
- 语音输入：Gemini 3.5 Transcribe / Live、OpenAI 兼容（Realtime/分段实时）、火山引擎流式、浏览器内置
- 停止回合：状态条/输入区双入口、`Esc`、乐观“停止中…”与强制结束兜底
- 输入区单行底栏：命令/文件/附件/语音 + 停止/发送，桌面与手机共用
- 附件：粘贴图片、拖拽/选择文件、缩略图与文件 chip；图片进 image content block，文本内联，其他文件按路径引用
- Web 原生命令：`/model` 模型面板、`/context`/`/usage`/`/status` 状态面板、`/permissions`、`/config`、`/help`；`<synthetic>` 消息显示为系统通知
- 旁问（/btw）：运行中基于当前上下文回答，禁工具、不写入主对话、不新增 Claude 会话文件；主输入框 `/btw` 打开同一面板
- 历史分页：按可渲染事件分页（过滤 token delta），滚到顶部自动加载更早消息
- 运行中追加消息：立即进入对话；`queued` → `delivered`/`failed` 状态可见，模型在下一回合边界看到
- 桌面/手机响应式、亮/暗/跟随系统；服务端默认外观
- 用户级/系统级安装脚本、systemd、卸载

## 已知限制

- 实时语音依赖渠道能力：Gemini Live 需要支持地区的 WebSocket 中转；OpenAI Realtime 需要账号权限或兼容网关；OpenAI 分段实时与火山引擎实时需要真实凭证实测。
- 麦克风需要 HTTPS/localhost。
- 会话进程随 Node 服务重启而终止；正在执行的回合会中断，已完成历史可继续。
- 大历史默认加载最近 240 条，可手动加载更早。

## 后续优先级

1. **交互补齐**：检查点/回退；旁问历史持久化与多问题并行。
2. **输入补齐**：更多 Slash/Skill 快捷操作；附件配额与过期清理策略。
3. **语音**：Live 断线重连、可调 VAD 阈值/麦克风设备选择、AudioWorklet。
4. **可观测性**：用量趋势、会话搜索、导出 transcript、通知（完成/待审批）。
5. **可选开发面**：文件树/编辑器、Git 面板、终端。它们会让产品变重，默认不进入核心。
6. **超长会话性能**：历史窗口虚拟化、transcript 压缩/归档；当前 compact 分页已解决消息可见性，但超大文件仍会整份读取。
7. **部署增强**：Docker Compose、统一身份网关示例、多用户/团队。

## 原则

- 保持“会话优先、结构化、手机可用”。
- 不把控制台做成无结构终端或完整 IDE。
- Claude Code 能力跟随 CLI/Agent SDK；控制台只做宿主、持久化与视图。
- 任何安全相关默认值优先“可收紧”，危险模式必须显式提示。
