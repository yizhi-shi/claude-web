# 部署模板

> 状态: reference
> 最后核对: 2026-11-23

这些文件是**示例**，不是可直接运行的线上配置。把 `example.com`、路径和端口替换成你的值。

## 拓扑

```text
浏览器
  │ HTTPS/WSS
  ▼
反向代理（nginx / Caddy / 统一身份网关）
  ▼
Claude Code Web   0.0.0.0:8010
  │
  └─ claude CLI（以服务运行用户身份，读取 ~/.claude）
```

## 步骤

1. 用 `install.sh` 在目标主机安装服务（默认 `~/.local/share/claude-web`）。
2. 如果服务只在局域网，直接访问 `http://<LAN-IP>:8010`。
3. 如果走公网：
   - 反向代理到 `127.0.0.1:8010`（同机）或内网主机；
   - 开启 WebSocket upgrade；
   - 关闭代理缓冲并放长读超时；
   - 建议叠加统一身份网关 / 基本认证。
4. 首次打开设置管理员账号。
5. 若使用语音，配置渠道 Key；火山引擎渠道需要 `ffmpeg`。

## 关键约束

- WebSocket 心跳 25s；反向代理/WAF 的空闲超时通常 100s，已留余量。
- `client_max_body_size` 至少 16m：语音以 base64 JSON 上传。
- 不要把 `data/` 暴露为静态目录。
- `HOST=0.0.0.0` 是默认值；若只经过本机反代，可改为 `127.0.0.1`。
- 服务运行用户必须能读取 `~/.claude` 和目标工作区目录。
